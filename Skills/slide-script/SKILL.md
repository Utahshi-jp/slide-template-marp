# slide-script — 台本生成

## トリガーワード

- 「台本を作って」「スピーカーノートを書いて」
- 「読み原稿」「セリフを書いて」
- スライド生成完了後の自動呼び出し

## ペーシング指針

- **1 スライド ≒ 180 字 ≒ 約 1 分** が基準
- LT(5 分): 5〜8 枚 / 700〜1000 字
- セッション(15 分): 15〜25 枚 / 2500〜4000 字
- セッション(30 分): 25〜40 枚 / 5000〜7000 字

実時間と枚数から逆算し、各スライドの話量を調整する。

## 実行手順

### Step 1: 入力読み込み

1. `output/YYYYMMDD_xxx.md` を Read してスライド構成を把握
2. `input/input.md` を Read して話したかった意図を把握
3. `templates/script_template.md` を Read して形式を踏襲

### Step 2: メタ情報の決定

冒頭に以下を書く:

- 想定時間
- 想定聴衆
- 目的(1 文)
- コール・トゥ・アクション

`input/input.md` から推定。不明ならプレースホルダ `{ }` のまま残す。

### Step 3: スライドごとの台本生成

スライド 1 枚につき:

```markdown
## スライド N: {見出し}

> 話す内容(180 字目安):
> {実際の話し言葉。です/ます調}

- 強調点: {ここでトーンを上げる、間を取る、など}
- 切り替えタイミング: {次のスライドへのつなぎワード}
```

### 文体ルール

- **話し言葉**: 「〜なんです」「〜と思います」可
- **敬語**: です/ます調で統一
- **読み上げ前提**: 漢字が多すぎないか確認
- **数字は読み方を明示**: `30%` → 「さんじゅっパーセント」など読みを括弧で付ける場合あり

### Step 4: Q&A 想定

スライド本体から想定されそうな質問を 3〜5 個ピックし、回答骨子を書く。

### Step 5: 当日チェックリスト

`templates/script_template.md` のチェックリストをそのまま転記。
登壇者が前日にチェックできる粒度に保つ。

### Step 6: 出力

`output/YYYYMMDD_xxx_script.md` を Write。

## 守ること

- **時間バランス**: 重要スライドに 240 字、つなぎスライドに 120 字、と濃淡を付ける
- **重複回避**: スライドのテキストをそのまま読み上げない。補足や具体例を語る
- **タイミング指示**: 切り替えタイミングを必ず書く(リハーサル時の道標)
- **過度な詳細禁止**: 1 スライドの台本は最大 300 字まで(緊張時に読み切れない)
