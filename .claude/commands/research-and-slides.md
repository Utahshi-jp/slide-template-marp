# /research-and-slides

引数 `$ARGUMENTS` をトピックとして Web 調査し、その結果を入力としてスライドを生成する。

## 実行内容

1. **調査フェーズ**:
   - WebSearch で `$ARGUMENTS` に関する最新情報を収集(2026 年の情報を優先)
   - `resources/` 配下に既存の参考資料がないか Glob で確認、あれば Read で取り込み
   - 主要な事実・数字・引用元 URL をまとめる
2. **入力生成**:
   - 収集情報を `input/input.md` に整形して保存
     - タイトル / 目的 / 想定聴衆 / 想定時間 / セクション構成 / 主要メッセージ / 参考リンク
3. **スライド生成**:
   - `/generate-slides` の手順に従って `output/` にスライド・PDF・台本を生成
4. **完了報告**:
   - 生成ファイルのパスと、参照したソース URL の一覧を報告

## 想定ユースケース

- 「EPM 市場についてのスライド作って」→ 市場規模、競合、トレンドを調査して構成
- 「最近の React Server Components 動向で LT スライド」→ 公式ドキュメント・ブログを横断調査

## 補足

- ソース URL は必ず `output/*_script.md` の「参考リンク」にも転記する
- 引用は事実ベース。憶測や捏造数字は載せない
