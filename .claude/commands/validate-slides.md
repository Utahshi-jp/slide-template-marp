# /validate-slides

`$ARGUMENTS` が指す Marp Markdown を読み、CLAUDE.md の制約に対する違反をレポートする。

## チェック項目

| 項目 | 制限 |
|---|---|
| タイトル文字数 | ≤ 30 字 |
| 本文 1 行 | ≤ 40 字 |
| 1 スライド合計 | ≤ 400 字 |
| 1 スライド行数 | ≤ 12 行 |
| 画像枚数 / スライド | ≤ 2 枚 |
| 表 / スライド | ≤ 1 個 |
| コードブロック | ≤ 20 行 |
| 見出しレベル | h1〜h3 のみ |
| リスト階層 | ≤ 3 階層 |

## 実行内容

1. `$ARGUMENTS`(省略時は `output/` 配下で最新の `*.md`)を Read
2. `---` でスライドを分割
3. 各スライドについて上記項目を機械的にチェック
4. 違反一覧をテーブル形式で出力
5. 各違反に対し**修正案**を併記する(短縮 / 分割 / 別コンポーネント化)

## 出力フォーマット例

```
スライド制約検証レポート
検証対象: output/20260511_xxx.md
総スライド数: 19 / 違反スライド数: 2 / 準拠率: 89.5%

違反詳細
スライド 6 (世界のリーダーたちの声)
  違反: 行数超過 (現在 14 / 制限 12)
  修正案: 2 スライドに分割 (リーダー A / B + C の構成案)

スライド 15 (Claude Code との効果的な協働)
  違反: 行数超過 (現在 21 / 制限 12)
  修正案: 「3 つの重要ポイント」と「Tips」を別スライドに

CSS コンポーネント使用状況
- columns-3: 3 回
- highlight-box: 8 回
- metric-card: 3 回
- ...
```

## 補足

- 違反がある場合、ユーザが「直して」と言ったら自動修正に入る
- 「軽微」(1〜2 字の超過)と「重大」(2 倍以上の超過)を区別してレポートする
